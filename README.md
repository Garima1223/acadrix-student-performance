# Acadrix — Student Performance Prediction System

Capstone project · AIML Summer Internship 2026, IIHMF, MNNIT Allahabad

Acadrix predicts a student's final score from their attendance, assignment
score, internal assessment marks, previous semester score and weekly study
hours. It has two portals:

- **Teacher:** dashboard, student management (add/edit/delete, CSV import/export), attendance register,
  live predictions, Model Lab (model comparison), EDA charts, announcements, report cards
- **Student:** overview, subject performance, what-if simulator, goal planner, tips, notices, profile

## Run it

The trained model is already included, so running the app takes two commands:

```bash
pip install -r requirements.txt
python backend/app.py
```

Open http://localhost:5000.

To regenerate the dataset and retrain the models:

```bash
pip install -r requirements-train.txt
python -m ml.generate_dataset   # create data/students_dataset.csv
python -m ml.train              # clean, explore, train 3 models, save the best
```

## Project structure

```
ml/
  features.py           feature list, grades and risk bands (shared with the API)
  generate_dataset.py   seeded synthetic dataset (1,000 students, deliberately messy)
  train.py              Phases 3–7: preprocessing, EDA, feature selection, training, evaluation
  predictor.py          loads the saved model; predictions, factor impacts, goal plans
backend/
  app.py                Flask API + serves the frontend
  database.py           SQLite schema and demo seed data (instance/acadrix.db)
frontend/               HTML / CSS / JS single-page app
data/                   generated dataset
models/                 best_model.joblib + metrics.json (read by the Model Lab page)
reports/figures/        charts for the project report
```

## How the ML pipeline maps to the project phases

| Phase | Where | What happens |
|---|---|---|
| 2 · Data collection | `ml/generate_dataset.py` | 1,015 rows with 11 candidate columns |
| 3 · Preprocessing | `train.py → preprocess()` | removes duplicates and impossible values, fills missing values, encodes categories |
| 4 · EDA | `train.py → eda_figures()` | histogram, boxplots, scatter plots, correlation heatmap |
| 5 · Feature engineering | `train.py → select_features()` | keeps features with \|r\| ≥ 0.15; engineered features kept only if they improve CV accuracy |
| 6 · Model building | `train.py → build_models()` | Linear Regression, Random Forest, XGBoost |
| 7 · Evaluation | `train.py → main()` | MAE, MSE, RMSE, R² on a 20% test set + 5-fold cross-validation |
| 8 · Deployment | `backend/app.py` | Flask serves the best model to the web app |

The best model (highest test R²) is saved and used for every prediction in the app.
"Factor impact" bars show how far the score moves when that factor is set to an
average student's value.

**About the dataset:** it is synthetic, generated by a seeded script so the
results are reproducible. To use a real dataset instead, give it the same
column names as `data/students_dataset.csv` and rerun `python -m ml.train`.

## API overview

All endpoints except login need `Authorization: Bearer <token>`.

| Method | Path | Who |
|---|---|---|
| POST | `/api/auth/login`, `/api/auth/logout` | anyone |
| GET | `/api/bootstrap` | both (students get only their own record + class averages) |
| POST | `/api/predict` | both |
| POST | `/api/goal-plan` | student |
| GET/POST/PUT/DELETE | `/api/students`, `/api/students/<id>`, `/api/students/bulk`, `/api/students/reset` | teacher |
| GET/POST | `/api/attendance` | teacher |
| POST/DELETE | `/api/notices`, `/api/notices/<id>` · POST `/api/notices/seen` | teacher · student |
| PUT | `/api/me/goal`, `/api/me/password` | student |
| GET | `/api/model`, `/api/figures/<name>` | both · teacher |

Passwords are stored as salted hashes, sessions expire after 7 days, and
repeated failed sign-ins are rate-limited.
